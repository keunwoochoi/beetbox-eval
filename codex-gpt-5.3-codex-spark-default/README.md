# Beetbox

This is a faithful recreation of the Beetbox web app from `beetbox.mov` and `beetbox_frames/`.

## Run

Open `index.html` directly in a browser, or serve it from a static web server.

## Notes

- The UI is implemented with pure HTML/CSS/JS.
- No external libraries are required.
- Layout is based on OCR and visual structure from the provided reference frames.

# BEETBOX

A faithful, dependency-light recreation of the beat sequencer shown in the supplied reference video.

## Run locally

```sh
npm install
npm run dev
```

Open the URL printed by Vite. Use the transport button or Space to play, click cells to edit the sequence, choose channel presets, randomize or clear the pattern, mute tracks, record keyboard notes, and play the A/S/D/F/G/H/J note row.

## Production build

```sh
npm run build
npm run preview
```
